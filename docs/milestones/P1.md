# P1: make the repository public

Status: spec (written before code; not edited after approval)
Roadmap ref: none (post-submission; the take-home was closed on 2026-10-14)

## Goal
The repository can be made public without publishing documents whose origin or licence is unknown: the 12 documents downloaded from
the internet are gone from the tree AND from every commit, the committed result reproduces on what is left, the README says plainly what the
public dataset is, and the code has a licence.

## Scope
- Drop 12 documents (their `license_note` is "internet downloaded", no `source_url`): doc_001, doc_002, doc_003, doc_005, doc_006,
  doc_007, doc_008, doc_009, doc_014, doc_015, doc_018, doc_031. They were the only `faktur` documents (11) plus one e-commerce bill.
- Strip those ids, and doc_004, doc_010 and doc_017 (excluded from the dataset on 2026-10-08 but still in old commits), from ALL history:
  pages, labels, drafts and per-document result records. Authorship and commit messages are kept; commit SHAs change.
- Make the committed evidence consistent with 23 documents (20 own, 3 constructed): manifest rows, a ground-truth CHANGELOG line, a new
  reproducible result `results/test-public` (test split, 16 documents, replayed from the response cache, scored offline), the three original
  runs kept as aggregate scorecards only under `results/original-dataset/`.
- README: the dataset and result sections rewritten for 23 documents; a "Known limitations" section (the `x1`/`2x` grounding gap, the
  constructed-vs-real row F1 split, the missing faktur type, no redaction boxes ever applied); a licence line.
- Add `LICENSE` (MIT, 2026) and the `license` field in `pyproject.toml`.
- DEVLOG entry; a short "Public release" bullet in CLAUDE.md.

## Out of scope
- The grounding bug itself (`x1`/`2x` quantities): the next session, as its own milestone. The public result is measured WITH the flaw, and
  the README says so.
- Pushing, creating a GitHub repository or changing visibility: the owner does it (the old private repository still holds the old history).
- Changing git identity, config or authorship.
- Re-running the model for any document that is not a cache hit.
- Editing the analysis reports in `docs/eval/` and `docs/demo/`: they were written on the 35-document dataset and are described as such in the README.

## Files
- Create: `LICENSE`, `docs/milestones/P1.md`, `results/test-public/` (via `scripts/promote_run.py`), `results/original-dataset/`.
- Change: `data/manifest.csv`, `ground_truth/CHANGELOG.md`, `README.md`, `results/README.md`, `CLAUDE.md`, `docs/DEVLOG.md`, `pyproject.toml`,
  and any test that reads a dropped document (found by running the suite).
- Delete: `data/pages/<id>/`, `ground_truth/<id>.json`, `ground_truth/drafts/<id>.json` for the dropped ids; `results/test-g2/`; the per-document files
  of `results/superseded/*`.
- Must NOT touch: `src/` (no behaviour change), `data/probes/` and `results/probes/` (synthetic), `ground_truth/` labels of the kept documents,
  `data/private/` (the owner's local originals stay on disk), `.env`.

## Acceptance criteria
Offline and deterministic except step 4. History checks run after the rewrite.
1. `git log --all --name-only --format= | grep -E "(^|/)(doc_00[1-9]|doc_010|doc_014|doc_015|doc_017|doc_018|doc_031)([/.]|$)"` -> no output.
2. `git rev-list --objects --all | grep -E "data/pages/doc_(001|002|003|004|005|006|007|008|009|010|014|015|017|018|031)/"` -> no output.
3. `python tools/secret_scan.py --history` and `--worktree` -> 0 findings.
4. [COSTS MONEY: expected $0, at most one live call about $0.01 under a cost cap of $0.0001] `eval_api.py --split test --run-id test-public` against a
   local API: 16 documents, all `cached`.
5. `python -m uv run python scripts/check_results.py` -> `test-public: reproduces`.
6. `python -m uv run python scripts/check_ground_truth.py` -> clean; manifest has 23 rows.
7. `python -m uv run pytest -q -m "slow or not slow"` and `python -m uv run ruff check` -> green.
8. `LICENSE` exists and `pyproject.toml` names it; README links resolve (every `results/...` path it cites exists).
9. A bundle of the pre-rewrite repository exists outside the repository directory.

## Risks
- A history rewrite is not undoable in place -> `git bundle` of every ref first, kept outside the repo; the private remote is untouched.
- Old objects survive in the private remote and, on GitHub, can stay fetchable by SHA after a force push -> the owner publishes through a NEW repository, not by
  flipping this one (README of the hand-over says so).
- The public dataset has no faktur document and 6 blind labels (was 10) -> stated in the README, not hidden.
- 20 own pages were never redacted (`data/redactions.yaml` is empty) -> the owner looks at them before pushing; I do not read real pages (CLAUDE.md).
- Tests that quietly depend on a dropped document -> found by running the full suite, fixed in the test, never by loosening an assertion.
