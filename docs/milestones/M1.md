## What was not verified
- **Live smoke run.** I ran `smoke.py` end to end only against a throwaway fake server that I wrote. It replied with a canned answer, so it showed the wiring works (image upload, fallback, cost maths) and nothing about real model behaviour. To run it for real, put `LLM_*` in `.env` and run `uv run python scripts/smoke.py`.
- **Gemini and structured output.** Unconfirmed: whether Gemini's compatibility endpoint accepts the simplified `json_schema`, or falls back cleanly when it doesn't.
- **Strict `Field` rules.** The schema rejects a field that is "extracted" with a null value, or "abstained" with a value. That may be too strict for real model output, and the first live run will show it.
- **Cost for "thinking" models.** If reasoning tokens aren't counted in `completion_tokens`, reported cost could be too low.

## Live run (synthetic receipt, Google's OpenAI-compatible endpoint)
- **Your model is dead.** `gemini-2.5-flash` returns 404, "no longer available to new users". It came from my `.env.example`, so I fixed the example. I did not touch your `.env`.
- **Model fallback.** `gemini-3.8`, `3.7` and `3.6-flash` returned 503 "high demand" on every retry, and nothing was billed. `gemini-3.5-flash` answered, so I used it, with model and prices passed as per-process overrides.
- **`json_schema` was accepted** on both runs. No fallback happened.
- **Raw vs parsed:** the content is identical. Money keeps its exact scale (`4.50`, `9.00`, `16.00`), because the model emitted those literals and `parse_float=Decimal` kept them.
- **Strict Field rules:** all 13 fields and 3 rows passed with 0 repairs. The fields it judged absent came back with confidence 1.0 and no reasons, which the rules allow. The validators flagged nothing.

| | Run 1, default reasoning | Run 2, `reasoning_effort=low` |
|---|---|---|
| Tokens in / out | 1388 / 2505 billable (1185 completion + 1320 reasoning) | 1388 / 1192 |
| Cost at list price | $0.0246 | $0.0128 |
| Latency | 28 s (including one 503 retry) | 21.5 s |

- **Reasoning tokens:** Google's `usage` block is only `{prompt, completion, total}_tokens`. The 1320 reasoning tokens exist only as a gap in `total_tokens`. A naive cost would have been 48% too low, so the reconciliation was necessary, not just defensive.
- **`reasoning_effort=low`** was accepted, and the hidden reasoning disappeared.

## What you need to do
Update your own `.env`: `LLM_MODEL=gemini-3.5-flash`, `LLM_PRICE_INPUT_PER_MTOK=1.50`, `LLM_PRICE_OUTPUT_PER_MTOK=9.00`. Optionally set `MAX_RUN_COST_USD` too. The `gemini-3.6`–`3.8` models cost $0.75 / $3.75 per 1M until 2026-12-31, once they stop returning 503s.
